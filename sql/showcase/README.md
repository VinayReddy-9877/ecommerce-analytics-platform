# SQL interview showcase

Ten PostgreSQL queries each start with a business question. Run after `olist run`.
`python scripts/export_showcase.py` executes every query and writes the first 12 actual rows to samples/. Samples are previews, not entire result sets. `sqlfluff lint sql/showcase` checks formatting.

The order-status query is milestone coverage from a final snapshot, not reconstructed sequential conversion. Installments aggregate payments first. Retention sensitivity keeps the original eligible cohort and explicitly changes the outcome window. Read each query and reproduce it without notes before presenting it in an interview.
